# NodeDesk v0.8.0-alpha.0 — engineering milestone notes

**NOT a production release.** v0.8 is an experimental automation-tested
milestone for Windows/Linux; native interactive Windows/Arch GUI acceptance
is deliberately deferred to v0.9. There is no stable installer or full
MobaXterm parity claim. The previous v0.7.0-rc.1 was an engineering checkpoint,
not a separate published stable release.

## New functionality on top of v0.7

- SFTP POSIX chmod for regular remote files/directories, three octal digits,
  explicit confirmation, world-writable warning, stale metadata/symlink/
  special-bit refusal, and post-write mode verification. Non-atomic on an
  actively hostile or concurrently modified remote filesystem.
- Safe local SSH config preview: reads only fixed ~/.ssh/config on user action,
  at most 64 KiB and 40 literal Host entries; extracts only alias, HostName,
  User and Port. Does not evaluate Include, ProxyCommand, IdentityFile, Match
  rules, arbitrary SSH directives, or run commands. Preview only fills an
  editable form; no automatic network connection or catalog write.
- One-hop, opt-in and **transient** OpenSSH ProxyJump for SSH/SFTP **console
  tabs only**. Jump data is not persisted, validated as a single literal
  host/user/port and passed as separate argv. Target retains -F none and
  host-key trust. **OpenSSH jump subprocess configuration may differ and may
  evaluate the local jump-host SSH config.** Operators must inspect it and
  validate the jump server host key independently. GUI Files, RDP, VNC and
  VPN do not use this jump mechanism.
- Redacted, user-triggered SFTP transfer report download: direction, indexed
  item states and counts only; excludes host/user, filenames, filesystem
  paths, credential strings, authentication IDs and partial IDs. Files shows
  the expected path of a stopped .part with an explicit manual inspection
  warning. It does not delete orphaned files.
- Network diagnostics suppress late results after host/port changes or
  workspace close; this does not interrupt the bounded backend probe.
- App header and npm/Cargo/Tauri metadata use 0.8 development identifiers.

## Existing v0.7 transfer foundations

Independent bounded SFTP queues, explicit pause/retry, full-prefix and
full-result byte verification before manual upload/download resume, optional
unencrypted local checkpoint metadata, no overwrites, text preview/editor
with Save as new copy, SSH/PAM/key/agent, catalog/split panes, local PTY,
RDP via Guacamole, VNC WSS, OS-managed VPN profile controls and bounded
network diagnostics. There is no unattended transfer background daemon.

## Test boundaries

Automated browser contracts and disposable SSH/SFTP, RDP/VNC fixtures on
Windows/Linux are required at exact commit HEAD. Native desktop testing on
actual Arch/Windows remains **unexecuted** until the v0.9 integrated
acceptance campaign. Build-only or mocked tests must not be described as
native production validation. No real corporate VPN or customer host is used.
