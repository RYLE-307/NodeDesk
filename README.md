# NodeDesk

**RU** · [English](README.en.md)

Локальное приложение для работы с инфраструктурой на Windows и Linux.
Tauri 2 + React + TypeScript + Rust. Цель — функциональный паритет MobaXterm
и интеграции VPN, Proxmox, Zabbix, MikroTik.

## Текущий статус

Первый каркас `0.1.0-alpha.0`, не готовый клиент удалённого доступа.
Есть Tech Dark оболочка, раскрываемая навигация, переключение RU/EN,
пустая рабочая область и место под верхние вкладки.
SSH/RDP/SFTP, каталог с сохранением, реальные вкладки, split panes, темы
и мониторинг ещё не реализованы. При запуске сессии не открываются.

Это новая основа: архив `NodeDesk-v0.1.0-alpha-starter.zip` из прежнего чата
в текущей сессии не найден и не использовался. Возможности прежнего прототипа
не считаются перенесёнными.

## Утверждённые принципы

- Offline-first: каталог и настройки локальны, обязательного аккаунта и облака нет.
- Windows/Linux, русский и английский; Tech Dark по умолчанию.
- Пустая рабочая область при старте; вкладки сверху; раскрываемая навигация.
- Мониторинг опционален и выключен по умолчанию; автоподключений нет.
- Секреты в будущем хранятся отдельно в защищённом хранилище ОС.
- Паритет — дорожная карта, а не заявление о реализованных функциях.

## Разработка

Нужен Node.js 22.12+ (рекомендуется поддерживаемая LTS), npm, Rust stable
и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).
На Windows нужны MSVC Build Tools и WebView2, на Linux — WebKitGTK и инструменты сборки.

```sh
npm install
npm run dev          # только веб-оболочка
npm run build        # TypeScript и production frontend
npm run tauri dev    # отдельное desktop-окно
```

Сборка зависимостей требует интернета; offline-first относится к работе приложения.
Установщики отключены до подготовки иконок, лицензий и проверки платформ.
`package-lock.json` и `Cargo.lock` следует создать и закоммитить при первой
проверенной установке зависимостей, затем перейти на `npm ci`.
Состояние текущих проверок: [BOOTSTRAP.md](docs/BOOTSTRAP.md).
