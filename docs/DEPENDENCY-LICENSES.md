# Проверка лицензий

Решение MIT отложено. `UNLICENSED` в package.json и отсутствие license в Cargo.toml
фиксируют отсутствие выданной лицензии проекта на этой стадии, а не результат аудита.

## Область проверки

| Область | Статус |
| --- | --- |
| React, React DOM, TypeScript, Vite, plugin-react, типы и Tauri CLI | Выбраны; полный аудит дерева не завершён |
| Rust tauri, tauri-build и транзитивные crates | Не зафиксированы Cargo.lock; не проверены |
| WebView2, WebKitGTK, GTK и системные библиотеки | Проверить условия распространения по платформам |
| SSH/RDP/VNC/X11/VPN движки и sidecar-бинарники | Не выбраны и не включены |
| Иконки, шрифты и другие ресурсы | Внешние ресурсы не включены; используется системный шрифт |

До MIT: зафиксировать lock-файлы, выгрузить inventory со SPDX, версиями, источниками
и текстами лицензий, проверить транзитивные зависимости и бинарники; подготовить
THIRD-PARTY-NOTICES. Наличие MIT у UI-библиотеки не покрывает весь desktop-дистрибутив.
Особенно отдельно оценивать copyleft-компоненты и возможность отдельной установки
внешних программ. Новые зависимости проходят такую же проверку до распространения.

Официальные источники для сверки:
- https://github.com/facebook/react/blob/main/LICENSE
- https://github.com/tauri-apps/tauri
- https://github.com/vitejs/vite/blob/main/LICENSE
- https://github.com/microsoft/TypeScript/blob/main/LICENSE.txt

Эти ссылки — отправные точки, не подтверждение совместимости выбранных версий.
