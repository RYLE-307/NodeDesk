# Архитектура

## Решения

- Tauri 2: локальный Rust-процесс и системный WebView, без серверного backend.
- React/TypeScript: оболочка, каталог, верхние вкладки, локализация RU/EN.
- Rust: будущие сервисы сессий, проверка входных данных, хранение, адаптеры протоколов.
- Платформенные реализации Windows/Linux скрываются за общими интерфейсами.
- Мониторинг — отдельный opt-in модуль, не обязательная стартовая панель.

## Границы будущих модулей

`catalog` хранит группы и подключения с версионированием формата и миграциями.
`sessions` управляет жизненным циклом подключений и вкладок.
`protocols` содержит SSH/SFTP/RDP/VNC и прочие адаптеры.
`integrations` содержит VPN/Proxmox/Zabbix/MikroTik.
`secrets` хранит ссылки на защищённые секреты, а не пароли в каталоге.
Пока эти модули описаны, но не реализованы.

## Безопасность

По умолчанию нет сетевых запросов, слушающих портов, телеметрии, автозапуска VPN,
фонового мониторинга и автоподключений. Текущему окну не выданы plugin permissions.
Новые IPC-команды получают узкие разрешения и проверяют данные на стороне Rust.
Не передавать секреты в URL, логи, localStorage, Git или аргументы процессов.
Проверять SSH host keys и TLS-сертификаты; не добавлять тихий обход проверок.
Импорт конфигурации не должен запускать команды или устанавливать компоненты.

## Критерий следующего прототипа

Создать группу и подключение, перезапустить приложение, восстановить каталог
без восстановления активной сессии. Повреждённые данные обрабатываются без потери
исходного файла. Каталог не содержит секретов. RU/EN охватывают все новые строки.
