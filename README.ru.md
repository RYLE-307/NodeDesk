**RU** · [English](README.md)

NodeDesk — локальное приложение для системного администратора на Linux и Windows.
Tauri 2 + Rust + React/TypeScript. Цель — расширяемый аналог MobaXterm.
Без обязательного аккаунта, облака, телеметрии и автоподключений.

## Что уже работает

- Компактный каталог с вложенными группами, поиском, избранным, перемещением
  подключений между папками, правым кликом и изменяемой шириной панели.
- Русский/английский интерфейс, светлая/тёмная/системная темы, вкладки и split.
- Настоящие интерактивные SSH и SFTP консоли OpenSSH: ключи/agent, пароль/PAM,
  проверка host-key по known_hosts и защита от изменённых/отозванных ключей.
- Графический SFTP v3: локальная и удалённая файловые панели, навигация, бинарная
  загрузка/скачивание с подтверждением, запретом перезаписи, прогрессом и отменой.
- В v0.5: создание папок, переименование, удаление файлов
  и пустых папок с подтверждением, Drag & Drop одного файла между панелями,
  действия правым кликом и Shift+F10. Переименование локальной папки без перезаписи
  использует системные механизмы Linux/Windows.
- Локальное хранение каталога без сохранения паролей. Работа каталога офлайн;
  удалённые SSH/SFTP-сессии, естественно, требуют сети.

## Ограничения

Графический вход Linux использует OpenSSH, Windows — native пароль/keyboard-interactive
с заранее доверенным ключом сервера. Консольный SSH/SFTP сохраняет прежние возможности.
Есть последовательная передача до 50 файлов; нет фоновой возобновляемой очереди,
встроенного RDP/VNC/VPN, удалённого редактора, рекурсии и Drag & Drop папок.
В ветке v0.6 первый RDP-запуск открывает отдельное окно mstsc.exe (Windows)
или sdl-freerdp3 (Linux) по кнопке, без сохранения паролей.
Операции над удалёнными путями не являются изоляцией от недоверенного SFTP-сервера.
При прерванном upload на сервере может остаться `.nodedesk-*.part`.
Пароли не сохраняются в WebView/localStorage, но временно проходят через PTY/IPC.

**v0.5 слита в main. v0.6 PR #11 остаётся draft до проверки запуска RDP на Arch/Windows.**
[Точная спецификация безопасности, тестов и ограничений](docs/V0.5-SFTP-GUI.md).

## Сборка

Нужны Node.js 24 LTS, npm, Rust stable, OpenSSH, зависимости Tauri 2:
[инструкция](https://v2.tauri.app/start/prerequisites/). Arch: WebKitGTK;
Windows: WebView2 и MSVC Build Tools.
Нативная SSH-зависимость собирает vendored OpenSSL: нужны C-компилятор,
Perl и make (MSVC/NMake на Windows). Для проверки known_hosts нужен
ssh-keygen из OpenSSH Client; устанавливать SSH-сервер на клиент не требуется.

```bash
npm ci
npm test
npm run build
cargo test --locked --manifest-path src-tauri/Cargo.toml
npm run tauri dev
```

Зависимости фиксируются в `package-lock.json` и `src-tauri/Cargo.lock`.
При проблемах с официальным npm registry на Arch доступно зеркало:
`npm ci --registry=https://registry.npmmirror.com/`.

### Новое в проверяемой v0.5

Выбор нескольких обычных файлов галочками (до 50), последовательная загрузка
или скачивание с подтверждением всей очереди, прогрессом текущего файла
и остановкой оставшихся по кнопке «Отменить». Уже переданные файлы не
откатываются. Функция ещё требует ручной проверки на Arch; в `main` нет.

### Дополнение v0.5 — отчёт по передаче файлов

После групповой передачи NodeDesk показывает состояние каждого файла
(передан, ошибка, отменён, не запускался). Отчёт существует только в памяти
открытой вкладки. Кнопка «Выбрать видимые (до 50)» выбирает подходящие
обычные файлы, а перенос выбранной группы мышью использует тот же безопасный
очередной механизм с подтверждением. Это не фоновая или возобновляемая очередь;
проверка на Arch и Windows для этого набора ещё требуется.

### Совместимость графического SFTP с Windows

В draft PR #10 добавлен Rust ssh2/libssh2: пароль и keyboard-interactive
(включая PAM-вопросы Linux-сервера) через скрытый ввод панели входа.
Неизвестный, изменённый или отозванный host key блокирует вход до запроса
секрета. Новый ключ сначала независимо сверьте и примите в SSH-консоли.
Пароли не сохраняются, не передаются в argv/окружении и не журналируются.
Отмена native-передачи завершает файловую сессию: потребуется повторный вход.
Для прежнего OpenSSH ключа/агента снимите галочку интерактивного входа.
CA/certificates, смена пароля и произвольные цепочки смешанной MFA не входят
в этот срез. Linux сохраняет прежний OpenSSH auth bridge и обе консоли.

Linux CI использует настоящий isolated sshd/PAM; Windows CI — отдельный
loopback SSH/SFTP peer для native-клиента. Это не ручная GUI-приёмка и не
проверка Windows sshd/PAM. PR #10 остаётся draft, без слияния в main.
[Архитектура и точные ограничения](docs/V0.5-SFTP-GUI.md).

### VNC в v0.6 (проверяемый этап)

В каталоге появился тип подключения **VNC**, порт по умолчанию — 5900.
Кнопка «Открыть VNC» запускает установленный TigerVNC в отдельном окне.
На Arch нужен пакет `tigervnc`, на Windows — официальный TigerVNC Viewer.
Для прямого подключения разрешены **только X509Vnc/X509Plain**; небезопасный
VncAuth, анонимные TLS и подключения без пароля запрещены. Поэтому старые
VNC-серверы без X.509 пока не подключаются — позднее добавим защищённый туннель.
Пароль вводится в TigerVNC; NodeDesk его не получает и не сохраняет.
Буфер обмена отключён; экран в интерфейс NodeDesk пока не встроен.
[Безопасность, тесты, ограничения](docs/V0.6-VNC.md).
