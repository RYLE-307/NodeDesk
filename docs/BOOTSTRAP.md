## Следующая проверка в среде разработки

1. Установить Node/npm, Rust и системные prerequisites Tauri.
2. `npm install`, затем `npm run build`.
3. `npm run tauri dev`, проверить Windows и Arch Linux.
4. Закоммитить package-lock.json и src-tauri/Cargo.lock; перевести CI на npm ci.
5. Проверить запуск без открытых сессий и отсутствие фоновых запросов.
6. Выполнить аудит лицензий и notices перед выбором LICENSE и выпуском сборок.

Публикацию GitHub подтверждать отдельно URL репозитория и SHA коммита;
локальный коммит не является доказательством публикации.
